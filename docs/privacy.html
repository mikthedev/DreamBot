Privacy Policy

Dream Team Bot and DreamPoly · Effective 25 November 2026

This policy describes how the Discord application Dream Team Bot (including the DreamPoly activity) handles information when you add it to a server or launch it in Discord.

Who we are

Dream Team Bot is a Discord app for community servers: welcome and names, birthdays, music, Overwatch news, optional AI chat, and the DreamPoly table. Contact: open an issue on github.com/mikthedev/DreamBot or message the app owner on Discord.

Information we process

We only process data needed to run features you or your server enable:

  • Discord user IDs, usernames, display names, and avatars
  • Server (guild) IDs, channel IDs, and role IDs for settings you configure
  • Optional real names used for nicknames, if someone provides one
  • Optional birthdays, if someone saves one
  • Messages you send to the bot (slash commands, mentions, control-panel actions)
  • Voice audio you speak to the bot when Voice AI is turned on, for speech-to-text
  • Game / “play together” activity your server chooses to track
  • DreamPoly: your Discord identity (if you authorize it), seats at the table, and short-lived game state for that activity instance

We do not sell personal data. We do not use it for ads.

Why we process it

  • To provide the features you asked for (birthdays, music, AI replies, DreamPoly)
  • To remember server settings chosen by admins
  • To keep the bot working and diagnose failures

Where it goes

  • Discord — the platform you are using
  • Our host — the machine that runs the bot (SQLite on the bot host) and Vercel for DreamPoly
  • Inworld — when you chat with Dream AI
  • Groq — when Voice AI transcribes speech

Those providers process data under their own terms in order to deliver that feature.

How long we keep it

Server settings stay until an admin changes them or the bot leaves the server. Birthdays and names stay until you clear them or leave. Voice audio is sent for transcription and is not kept as a recording in our database. DreamPoly table state is tied to the activity instance and is not a permanent profile.

Your choices

  • Do not use optional features (AI, voice, birthdays, DreamPoly authorize)
  • Use /clearbirthday and admin panel tools to remove saved data
  • Kick or ban the bot from a server to stop further collection there
  • Ask the app owner on Discord or GitHub to delete stored records we control

Children

The app is meant for Discord users. Discord requires users to meet their minimum age. We do not knowingly collect data from children below that age.

Changes

If this policy changes in a material way, we will update this page and the date above.
